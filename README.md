# E-Commerce Website

A full-stack MERN E-Commerce platform with user authentication, product management, shopping cart, order processing, payment integration, and admin dashboard.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Redux Toolkit
- JWT Authentication

## Features
- User Authentication
- Product Catalog
- Shopping Cart
- Order Management
- Payment Gateway Integration
- Admin Dashboard
